이름
Deep Review HTML Exporter

한 줄 소개
열려 있는 Deep Review 리뷰를 하이라이트와 코멘트가 연결된 오프라인 단일 HTML로 저장합니다.

상세 설명
Deep Review의 논문 리뷰를 버튼 한 번으로 저장하고, 인터넷 연결 없이 다시 읽으세요.

로그인하여 열어 둔 리뷰에서 확장 버튼을 누르면 논문 페이지 이미지, 전체 피드백, 상세 코멘트와 하이라이트 연결을 단일 HTML 파일에 담습니다. 별도 작업 탭에서 진행 상태를 확인할 수 있으며 다운로드가 완료되면 확장 아이콘에 완료 표시가 나타납니다.

저장된 HTML의 기능
• Read More / Read Less로 전체 피드백 펼치기와 접기
• Report / Comments 보기 전환
• 하이라이트와 코멘트 사이의 양방향 이동 및 선택 표시
• 논문 이미지 확대·축소: 50–500%
• 심각도 필터, Dismiss와 복원
• 같은 리뷰의 전체 보고서 복사

사용 방법
1. Deep Review에서 저장할 리뷰를 엽니다. 필요한 로그인과 문서 접근 권한은 원본 서비스에서 준비합니다.
2. 확장 도구 모음 버튼을 한 번 누릅니다.
3. 완료 표시 후 Chrome 다운로드 위치의 DeepReview 폴더에서 HTML을 엽니다.

파일 하나에 화면 표시 자원과 동작 코드를 내장하므로 저장 후에는 확장 프로그램이나 로그인 없이 열 수 있습니다. 수집을 위해 임시로 바꾼 보기·필터·스크롤은 가능한 경우 원래 상태로 복원합니다.

처리 범위와 개인정보
사용자가 버튼을 누른 리뷰 화면의 내용과 문서 메타데이터를 기기에서 처리합니다. 개발자 서버로 업로드하거나 광고·분석에 사용하지 않습니다. Google 비밀번호, 쿠키, 인증 토큰이나 웹 저장소를 조회하지 않습니다. 원문에 들어 있는 이름·연락처 등은 선택한 문서 내용의 일부로 저장될 수 있습니다.

지원 범위
현재 Deep Review PDF 리뷰 화면의 한 리뷰 버전을 저장합니다. 논문은 페이지 이미지이므로 PDF 텍스트 검색·선택이나 벡터 확대는 지원하지 않습니다. 원본에서 이미 숨겨져 DOM에서 사라진 코멘트는 포함되지 않을 수 있습니다. 원본 사이트 구조 변경이나 브라우저 이미지 접근 제한 시 작업 탭에 오류를 표시합니다.

이 확장 프로그램은 독립 개발 도구이며 Google이 제공하거나 보증하는 공식 확장 프로그램이 아닙니다. 스토어 예시 화면은 실제 확장에서 내보낸 가상 문서를 사용합니다.
