단일 목적 설명
사용자가 열어 둔 Deep Review 문서의 페이지 이미지와 리뷰 피드백을 수집하여, 하이라이트와 코멘트가 연결된 오프라인 단일 HTML로 저장합니다.

activeTab 사용 근거
사용자가 도구 모음 버튼을 누른 현재 Deep Review 탭을 일시적으로 읽기 위해 필요합니다. 문서 주소와 화면 구조를 확인하고 현재 표시된 리뷰를 대상으로 수집합니다. 모든 사이트의 상시 접근 권한을 요청하지 않습니다.

scripting 사용 근거
확장에 포함된 격리된 수집 스크립트를 사용자가 선택한 탭에서 실행합니다. 논문 페이지 이미지·하이라이트 백분율 좌표·코멘트 HTML을 읽고, 수집을 위해 바꾼 보기와 필터·스크롤을 복원합니다. Google 앱 내부 변수, 인증 저장소 또는 원격 실행 코드는 사용하지 않습니다.

downloads 사용 근거
기기에서 생성한 단일 HTML Blob을 Chrome 다운로드로 저장하기 위해 필요합니다. 확장이 시작한 다운로드 ID만 추적하여 실제 완료·중단 여부와 저장 위치를 표시하며, 사용자가 선택하면 해당 파일을 폴더에서 표시합니다.

원격 코드 사용
아니요. 실행하는 JavaScript와 표시용 CSS·글꼴은 확장 패키지에 포함되어 있습니다. 원본 리뷰의 앱 스크립트는 내보내지 않습니다. 생성된 HTML은 내장 뷰어 런타임만 실행하고 외부 연결을 차단합니다.

호스트 권한
배포 매니페스트에 host_permissions 또는 optional_host_permissions를 선언하지 않습니다. 테스트용 복사본의 제한된 fixture 권한은 배포 ZIP에 포함하지 않습니다.

데이터 처리 항목 작성 근거
Website content: 페이지 이미지, 요약·리뷰 코멘트와 하이라이트 연결을 로컬에서 처리·저장합니다.
Web history: 선택한 문서 URL·제목·저장 시각을 HTML의 출처 메타데이터에 보존합니다. 처리 범위는 버튼을 누른 문서입니다.
Personally identifiable information: 선택한 문서에 이름·이메일 등 식별 정보가 있으면 이미지나 리뷰 본문의 일부로 포함될 수 있습니다. 계정 프로필을 별도 조회하지 않습니다.
개인 건강·금융 정보 등 다른 범주는 실제 처리하는 데이터와 대시보드의 정의에 따라 확인합니다. 논문의 연구 주제와 개인 건강 기록은 구분합니다.

제한적 이용 확인
처리한 데이터는 사용자가 요청한 오프라인 HTML 내보내기 기능에만 사용합니다. 판매·광고·신용도 평가·대출 판단에 사용하지 않습니다. 개발자는 확장이 처리한 리뷰 데이터에 접근하거나 이를 전송받지 않습니다.
