# Privacy documentation for GitHub distribution

The main English data-handling description is `docs/privacy.md`. The approved Korean HTML policy remains in `store/privacy-policy.ko.html`; `python scripts/sync_privacy_page.py` refreshes the local copy in `docs/privacy-policy.html`.

GitHub Releases is the sole planned extension distribution channel. Web Store submission is on hold. GitHub Pages is not required and is not enabled by these scripts. Links to source privacy documentation become public only after an approved source upload; local preparation does not make them live.

Publisher/contact values are the ones explicitly approved by the publisher. Do not infer personal details from Git configuration, local paths or accounts. Local processing still handles document content, which can contain personal information; the privacy description must accurately explain output identifiers, link cleanup and the absence of anonymization/encryption.
